入力内容を確認してください

    1. YouTube

    Google Cloud Console で発行した YouTube Data API v3 のキー。設定済みの場合は、変更するときだけ入力してください

    例：https://www.youtube.com/live/xxxxxxxxxxx

    取得するコメント

    短いほど速く反映されますが、API の1日の上限に早く達します

    開始時点でチャット欄に残っているコメントの扱い

    コメント取得の開始・停止は操作画面で行います。

    2. Singular Live

    Singular のコントロールアプリの API 設定で確認できるトークン。設定済みの場合は、変更するときだけ入力してください

    CG を出し入れする対象。大文字・小文字も一致させてください

    フィールドIDの対応

    Singular 側のコントロールフィールドIDを入力します。空欄の項目は送信しません

    送る内容Singular のフィールドID

    「金額帯の色」には YouTube と同じ色を #d00000 の形式で送ります

    「テスト太郎 ¥10,000」を送出します（表示時間が過ぎると自動で OUT）

    3. 送出のしかた

    送出方法

    0 にすると「OUT」を押すまで表示し続けます

    OUT のアニメーションが終わるまでの待ち時間

    4. サーバー

    他のアプリと重なる場合に変更します（1024〜65535）。アプリの再起動後に反映されます

    操作できる端末

    タブレットなど別の端末から操作する場合は「同じネットワークの端末」を選びます。アプリの再起動後に反映されます
