スーパーチャットCG（Windows 版）
================================

■ 起動
  superchat-cg.exe をダブルクリックします。
  ブラウザで操作画面が自動で開き、画面右下の通知領域（タスクトレイ）にアイコンが出ます。
  （開かない場合はブラウザで http://localhost:3000/ を開いてください）
  ・アイコンをクリック … 操作画面を開く
  ・アイコンを右クリック … 操作画面／設定を開く、ログを開く、終了
  ※ アイコンが見えないときは、タスクバー右下の「^」の中を確認してください。
  ※ すでに起動している状態でもう一度ダブルクリックすると、起動中の操作画面が開きます。

  ※ 初回は「Windows によって PC が保護されました」と表示されることがあります。
    「詳細情報」→「実行」を押してください（署名のないアプリのため表示されます）。
  ※ ファイアウォールの確認が出た場合は「許可」を押してください。

■ 終了
  タスクトレイのアイコンを右クリック →「終了」

■ 最初にすること
  1. 操作画面の上の「設定」を開く
  2. 配信の URL と Singular の Control App Token を入力して保存
     （サブコンポジション名・フィールド ID は「スーパーチャット」コンポジションに合わせて
       superchat / name / price / text / price_color / d_text / d_price が最初から入っています）
  3. 「保存してテストデータを送出」で Singular に CG が出るか確認
  4. 「操作」画面に戻り「取得を開始する」

■ ポート番号
  既定は 3000 です。他のアプリが使っている場合は、空いている番号（3001, 3002 …）で自動的に起動し、
  通知でお知らせします。決まった番号にしたいときは設定画面で変更してください（再起動後に反映）。

■ 保存されるファイル（exe と同じフォルダ）
  config.json  … 設定（API Key / Token を含むので他人に渡さないでください）
  state.json   … 取得中だったかどうか（再起動時の自動再開用）
  usage.json   … YouTube Data API の使用量
  superchat-cg.log … 動作ログ（トラブル時に確認してください）

■ 長時間配信の注意
  ・パソコンのスリープ・自動更新による再起動をオフにしてください。
  ・取得が途切れても、「取得を停止する」を押すまでは自動で再接続します。
  ・exe を再起動しても、前回取得中だった場合は自動で取得を再開します。
