## ダウンロード

下の **Assets** から `superchat-cg-windows-*.zip` をダウンロードし、展開した `superchat-cg.exe` をダブルクリックすると起動します（Node.js のインストールは不要です）。ブラウザで操作画面が自動で開き、タスクトレイに常駐します（コマンドプロンプトは開きません）。終了はトレイアイコンの右クリック →「終了」です。

- 初回は「Windows によって PC が保護されました」と表示されることがあります。「詳細情報」→「実行」を押してください（署名のないアプリのため）。
- 使い方は zip 内の `README.txt` を参照してください。

## 主な機能

- YouTube Live のスーパーチャット（必要なら通常コメントも）をリアルタイム取得し、Singular Live の CG に送出
- 取得方法：YouTube から直接（API Key 不要・上限なし）／YouTube Data API
- 複数の配信（最大 10）から同時に取得（設定画面で 1 行に 1 つ URL を入力）
- 自動送出（キュー順）・手動送出（タッチ操作向けの 2 段階）
- 長時間配信向け：自動再接続、再起動時の取得再開
- ポートが使用中なら空いている番号で自動起動、二重起動は起動中の画面を開く
